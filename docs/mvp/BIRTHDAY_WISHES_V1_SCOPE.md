# 生日祝福 V1 範圍

## 這個 PR 完成什麼

- 社員可針對每個有效社籍，自願公開生日的「月、日」。
- 預設不公開；沒有設定紀錄就視為關閉。
- 出生年份與完整生日不會出現在生日祝福資料投影。
- 同社有效社員每年可對同一位社員送出一則純文字祝福，並可修改或刪除自己的內容。
- 社長、秘書、有效社務管理者可輸入原因後隱藏不當祝福。
- 資料表不開放瀏覽器直接讀寫，所有操作都經過固定 `search_path`、檢查登入者與 `club_id` 的 RPC。
- `/birthdays` 有載入骨架、手機版版面與簡單中文錯誤訊息。

## 明確不在這個 PR

- 不做 AI 產生賀詞，也不自動發布任何內容。
- 不上傳照片、影片或語音。
- 不建立敏感的醫療、家庭或關懷個案紀錄。
- 不發 LINE／Email 通知；通知由公告與通知領域另外處理。
- 不變更 Supabase 權限設定或正式環境資料。

## 隱私原則

既有的 `show_birthday_year` 只代表是否在社員名冊顯示「年份」，不能當成公開月日的同意。生日祝福使用獨立、每社別的明確選擇，且預設關閉。
