# 生日祝福題庫 V1

> 狀態：預設題庫已寫入資料庫（`20260824000600_birthday_wish_collection_core.sql`）
> 用途：生日祝福自動邀約的引導題目
> 題數：100 題

這份題庫的題目是用來幫助社員想起與壽星相處的故事，不是可以直接複製送出的祝賀詞。
題目刻意保留回答空間，讓每個人寫出自己的話。

## 使用規則

- 題目只以問句呈現，不預填祝賀內容。
- 自動派發時，每個生日月份的同一批次不得重複題目。
- 題目派出後保存文字快照；幹部之後停用或修改題庫，不影響已派出的題目。
- V2 第一版可以跳過題目改用自由書寫，但不能換成另一個題目。
- 幹部可以新增、停用和排序社團題目；已被派出的題目只停用，不直接刪除。
- 題目避免詢問年齡、收入、婚姻、健康、家庭等可能讓人不舒服的私人資訊。

## 實作備註

- `tone` 可由檔案段落映射為 `warm`、`humorous`、`moving`。
- 題目分配時，優先在同一生日月份批次內避免重複；跨月份可再次使用，但應優先避開同一社員最近用過的題目。
- 這 100 題已作為平台唯讀題庫 seed；幹部不能修改平台題目，只能另外建立社團題目。
- 題目若要調整，必須新增 forward-only migration，並保留已派發題目的文字快照。
