# 祝福 IOU 收款範圍

本領域接在祝福 IOU 核心之上，負責授權幹部的收款登錄與錯帳沖銷。它不更改公開祝福牆的金額隱私，也不把收款狀態提供給一般社員。

## 完整能力

- 依月份查看每位社員的捐款承諾、已收與未收金額。
- 一次登錄單筆或最多 50 筆收款，可跨多位社員批次處理。
- 收款金額可以小於未收金額，形成部分收款。
- 同一筆承諾可分多次收款，但有效收款總額不能超過承諾金額。
- 錯帳不能修改或刪除；必須填原因沖銷，再重新登錄正確資料。
- 收款與沖銷紀錄永久保留，資料表禁止瀏覽器直讀、更新與刪除。
- 任何一筆承諾只要曾有收款紀錄，即使後來沖銷，社員與幹部都不能再修改或取消原始祝福。
- 收款 API 使用 `no-store`，不做跨使用者或跨社快取。
- 收款入口由獨立的 `blessing_iou_collections_v1` 控制，`DISABLE_BLESSING_IOU_COLLECTIONS=true` 可只關閉收款而保留祝福牆。

## 權限

`blessing_iou.collect` 只授予社長、秘書、財務與具有效社務管理權限的執行秘書。純平台管理員不會自動取得社內收款資料。

## 不在本領域

- 扶輪年度與跨月統計。
- Excel／PDF 匯出。
- 金流或銀行自動對帳。
- 一般社員查看收款狀態。

上述報表能力由下一個獨立領域提供，不改寫本領域的不可變收款軌跡。
