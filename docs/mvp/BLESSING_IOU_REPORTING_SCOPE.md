# 祝福 IOU 扶輪年度報表範圍

本領域直接彙總祝福 IOU 核心與收款紀錄，不建立另一份會過期的統計快照。每次讀取都以目前有效資料重新計算，因此沖銷會立刻反映在報表中。

年度查詢使用 `club_id + pledged_on` 的局部索引，只掃描有效且有承諾金額的資料，避免祝福紀錄累積後拖慢報表。

## 扶輪年度定義

- 每個扶輪年度固定從 7 月 1 日開始，到隔年 6 月 30 日結束。
- 例如 `2026-27` 扶輪年度為 2026-07-01 至 2027-06-30。
- IOU 歸屬月份依祝福承諾的 `pledged_on` 計算，不因晚繳而移到其他月份。

## 完整能力

- 全年承諾、有效收款、未收金額、IOU 筆數與社員人數。
- 未收、部分收款、已收清筆數。
- 固定 12 個月份的承諾、已收與未收統計，沒有資料的月份也會顯示 0。
- 每位社員的年度承諾、已收、未收與收款進度，依未收金額排序。
- 可切換過去扶輪年度，不允許查看未來年度。
- 已沖銷收款不計入有效收款；沖銷歷史仍由收款領域保留。

## 權限與快取

- `blessing_iou.report` 只授予社長、秘書、財務與具有效社務管理權限的執行秘書。
- 純平台管理員不會自動取得社內報表。
- 報表不包含祝福文字、聯絡資料或公開牆內容，只回傳必要的社員名稱與彙總金額。
- 報表 API 使用 `no-store`，不做跨使用者或跨社快取。
- 報表入口由 `blessing_iou_reporting_v1` 控制，`DISABLE_BLESSING_IOU_REPORTING=true` 可單獨關閉。

## 不在本領域

- Excel／PDF 匯出。
- 銀行或金流自動對帳。
- 一般社員查看自己的收款狀態。
- 跨社平台財務彙總。
