# 介面設計企劃書：從「能用」到「看起來被認真對待」

建立日期：2026-09-14（Asia/Taipei）

範圍：56 個頁面、23 份樣式檔、`src/app/globals.css`（341 行）為設計系統核心。

本文件不是風格提案，是**一份有證據的檢討與一套可執行的規則**。設計決定都附上它解決的具體問題。

## 1. 先講最重要的發現

**這個專案的介面違反了它自己寫的無障礙標準。**

`UX_SENIOR_FRIENDLY_AUDIT_PLAN.md` §4.1 明定：

> 正文至少 16px；輔助文字不低於 14px。10–12px 只可用於不影響理解的品牌小字，不可用於主要狀態或操作。

實際狀況：

| 字級 | 宣告次數 |
|---|---|
| 13px | 23 |
| 12px | 17 |
| 11px | 10 |

而 `.subtle` 與 `.hint`（兩者都是 13px）在元件中被使用 **55 次**，承載的是「填了之後社員到現場可以直接用手機定位簽到」這類**真正要讀的說明文字**，不是品牌小字。

這不是美感問題，是**規範沒有被落實到設計系統裡**。只要 token 允許 13px，每個人都會用 13px。

## 2. 為什麼現在看起來不高級

以下每一條都指向具體的程式碼，不是主觀感受。

### 2.1 所有東西都在強調，於是沒有東西被強調

現行字重同時存在 **850、800、760、700、650**：

- `.eyebrow`：12px + `font-weight: 850` + `text-transform: uppercase` + `letter-spacing: .18em`
- `.button`：`font-weight: 800`
- `.metric-label`：`font-weight: 700`
- h1：`font-size: clamp(30px, 4vw, 46px)`

當標籤、按鈕、數字、標題全都用最重的字重喊話，畫面就只剩噪音。高級感來自**克制**——讓少數元素承擔強調，其餘退後。

### 2.2 邊框與陰影同時存在

`.card` 是 `1px 邊框` ＋ `0 10px 30px rgba(18,48,74,.08)` 的大範圍陰影。兩者都在做「把卡片抬起來」這件事，同時用就顯得用力。

而且**全站只有一個陰影值**，意思是所有東西的「高度」都一樣——沒有真正的層次，只有一層統一的浮起。

### 2.3 CJK 標題用了負字距

```css
h1 { letter-spacing: -.035em; }
```

負字距是拉丁文 display 字體的手法。**中文字本身已經是等寬方塊，負字距會讓筆畫互相擠壓**，在 40px 以上特別明顯。這同時是美感與可讀性問題。

### 2.4 Eyebrow 被過度使用

幾乎每張卡片與每個頁首都有一行大寫寬字距的小標。原意應該是點綴，但在這個密度下它變成每個區塊都要先讀一行噪音，而且**每處都吃掉一行高度**。

### 2.5 間距沒有尺度

現行值包含 30、28、24、22、20、18、16、14、12、10、8、6、4 px，看得出是逐元件挑的。沒有尺度，畫面的節奏就是隨機的——這是「業餘感」最常見的來源，比顏色更致命。

### 2.6 金色幾乎沒被使用

扶輪的識別是**深藍＋金**。但 `--gold` 目前只出現在品牌圓標與頭像底色，其餘強調色一律用 `--blue: #1677a8`——一個沒有來歷的通用藍。

## 3. 設計方向：什麼是「全年齡向的高級感」

必須先否定一個常見的誤解。**對這個使用者群（多為中高齡專業人士），高級感不是**：

- 更細的字重
- 更低的對比
- 更小的字
- 極簡到資訊不足

**而是**：

- **留白充足**——讓內容有呼吸，而不是塞滿
- **克制的色彩**——少數顏色，用得準
- **明確但不喧鬧的層級**——大小與間距決定重要性，不是靠字重與大寫
- **對齊與節奏的品質**——一致的尺度讓畫面顯得「被設計過」

這個方向與長者友善**完全不衝突**，反而是同一件事：留白、層級清楚、對比足夠，對所有年齡都更好讀。

## 4. 規則

### 4.1 字級尺度（全部 ≥ 14px）

| Token | 值 | 用途 |
|---|---|---|
| `--text-display` | `clamp(28px, 3.2vw, 40px)` | 頁面主標題 |
| `--text-title` | `22px` | 區塊標題 h2 |
| `--text-subtitle` | `18px` | h3 |
| `--text-body` | `16px` | 正文（最低） |
| `--text-small` | `14px` | 輔助文字（**地板，取代所有 13px**） |
| `--text-micro` | `12px` | **僅限**品牌小字與 eyebrow，不得用於說明或狀態 |

h1 從最大 46px 降到 40px：46px 配上負字距在中文下既擠又吵，40px 已足夠建立層級。

### 4.2 字重只用三級

| 值 | 用途 |
|---|---|
| `700` | 標題與主要按鈕 |
| `600` | 次要強調、標籤 |
| `400` | 正文 |

移除 850／800／760／650。**字重不是用來分類的，是用來分層的。**

### 4.3 字距

- 中文標題 `letter-spacing: normal`（移除負值）
- eyebrow 保留寬字距（那是拉丁大寫，適用）

### 4.4 層次：邊框或陰影，不並用

| Token | 用途 |
|---|---|
| `--elevation-flat` | 卡片：**只有邊框**，無陰影 |
| `--elevation-raised` | 浮動面板、選單：柔和陰影，無邊框 |

卡片是頁面的基底，不需要浮起。真正需要「浮在內容之上」的只有選單與彈出面板。

### 4.5 間距尺度

`4 / 8 / 12 / 16 / 24 / 32 / 48`，以 token 提供。所有新樣式只能從中取值。

### 4.6 顏色

- `--navy` 維持主色
- `--gold` 提升為**唯一的強調色**，用於品牌標記與分隔線裝飾
- **金色不得用於文字**：`#d5a92e` 在白底上對比僅約 2.2:1，遠低於 4.5:1 的門檻
- eyebrow 從藍色改為 `--muted`，讓它退回輔助地位

## 5. 不會改的東西

- 48×48px 觸控區
- 320／375／412px 無水平捲動
- 200% 文字放大仍可完成核心流程
- 顏色不得作為唯一狀態指示
- 既有的元件結構與 class 名稱——**這一輪只換 token 與基礎層**，不重寫 56 個頁面

## 6. 為什麼從 token 下手

56 個頁面逐頁重畫是不可能在一輪完成的，而且會製造大量衝突（Codex 同時在開發）。

**改 token 與基礎層，56 個頁面會一起改變**，因為它們都吃同一份 `globals.css`。這是投入產出比最高的一刀，也最不容易跟別人的工作撞車。

後續的逐頁精修另立任務。
