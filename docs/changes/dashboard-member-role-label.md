# Dashboard member role label fix

The dashboard previously treated every non-platform account as an executive secretary. The presentation now derives the label from the returned club permission level:

- platform access: 平台管理員
- club_manager: 執行秘書
- ordinary club membership: 一般社員
- no club access: 一般使用者

The club-count wording also distinguishes clubs the account manages from clubs the account has merely joined.
